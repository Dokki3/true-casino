# Честное казино

Четыре стола на pygame с одним общим кошельком: видеопокер с прогрессивным
джекпотом, европейская рулетка, блэкджек и кости. Виртуальные деньги, никаких
сохранений, никакого доната. Код раздачи открыт и проверяется тестами — в этом
вся идея.

## Запуск

```
python -m pip install pygame-ce
python main.py
```

Каждый запуск — новая сессия с **$10 000**. Баланс общий: вы просто носите
фишки между столами, как в настоящем зале. Переключение — вкладки сверху
справа или `Tab`. Уйти со стола посреди раздачи нельзя: вкладки гаснут, пока
деньги в игре.

Ничего не пишется на диск, так что «подкрутить» прогресс между запусками
просто негде.

## Столы

| Стол | Правила | Отдача |
| --- | --- | --- |
| Видеопокер | Jacks or Better 9/6 и Deuces Wild, до 29 рук за раздачу, джекпот на роял | 99.54% / 100.76% |
| Рулетка | европейская, одно зеро, la partage | 97.30%, на равных шансах 98.65% |
| Блэкджек | 6 колод, блэкджек 3:2, дилер стоит на мягких 17 | ~99.6% с базовой стратегией |
| Кости | два кубика, точка и три броска на повтор | 137.7% (авторские) или 99.2% (честные) |

### Видеопокер

Главная рука меняет карты из своей же колоды, поэтому сброшенная карта в ней
больше не появится. Каждая дополнительная рука берёт свою свежую колоду без
закреплённых карт: 29 рук — это ровно то же самое, что 29 раз сыграть одну
руку, только за одно нажатие. Руки вскрываются по очереди, деньги набегают
вместе со вскрытием. Полная таблица выплат — в `paytable.py`.

**Джекпот**: 1% каждой покерной ставки капает в счётчик, стартовавший с
подаренных заведением $50 000. Натуральный роял-флеш забирает джекпот, если
тот больше обычных x800. Честно говоря: при одном игроке это не «общий банк
зала», а ваш собственный отложенный процент плюс сид заведения, то есть покер
от джекпота становится чуть выгоднее, а не наоборот.

### Рулетка

Клик по центру числа — ставка на число, по границе — сплит, по углу — каре,
по внешнему краю ряда — стрит и линия. Снизу дюжины, колонки и равные шансы.
`ОЧИСТИТЬ` убирает фишки, `ПОВТОР` возвращает ставки прошлого круга.

Край 2.70% берётся из того, что колесо платит как за 36 чисел, а чисел 37.
Правило **la partage** возвращает половину ставки на равных шансах при зеро и
режет край на них до 1.35% — это самая честная рулетка, которая существует.

### Блэкджек

Шуз из 6 колод с перетасовкой при проходе 75%; остаток виден на экране, так
что карты можно считать и честно получить перевес над заведением. Блэкджек
платит 3:2 (никогда 6:5), дилер стоит на мягких 17, дабл на любых двух и
после сплита, сплит до четырёх рук, поздняя сдача, страховка 2:1.

Клавиши: `H` — взять, `S` — хватит, `D` — дабл, `P` — сплит, `U` — сдаться.

### Кости

Первый бросок: 2, 3 или 12 — проигрыш; 7 или 11 — выплата x2; любое другое
число становится точкой. Дальше до трёх бросков: повтор точки платит x4,
семёрка проигрывает, а если за три броска не выпало ни того, ни другого —
ставка возвращается.

Эти правила щедры к игроку: отдача **137.7%**, потому что настоящий крэпс за
повтор точки платит x2, а не x4. Рядом лежит переключатель «Честные», где
точка платит x1.75 и отдача выходит 99.2%. Отдача считается точной формулой по
всем 36 исходам прямо в коде и показана на экране — какие числа ни поставь в
`games/dice.py`, игра сама напишет свою настоящую отдачу.

## Почему это честно

* Колоды, колесо и кубики крутятся через `random.SystemRandom` — системный
  источник энтропии ОС, а не генератор с воспроизводимым seed.
* Ни одна функция раздачи не видит ни баланса, ни ставки, ни истории: раздать
  карту — это снять её с верха уже перетасованного списка.
* Деньги ходят только через банк (`bank.py`), и баланс сходится до рубля:
  `баланс = старт − поставлено + возвращено`.
* Ничего не сохраняется между запусками, значит нет и скрытого «профиля
  игрока», по которому можно было бы подкручивать.

Проверяется это тестами (`python tests.py`, ~18 секунд, 19 проверок):

* полный перебор всех 2 598 960 пятикарточных рук со сверкой количества каждой
  комбинации с известными математическими значениями;
* эвалюатор с джокерами против тупого полного перебора всех подстановок;
* средняя выплата на 150 000 реально раздаваемых колод против точного
  математического ожидания;
* равномерность тасовки по критерию хи-квадрат;
* отдача каждой из восьми ставок рулетки равна ровно 36/37, а la partage даёт
  98.65%;
* разбор клика по сукну: центр, границы и углы дают правильные типы ставок;
* блэкджек: 3:2, страховка, пуш, дабл, сплит, сдача и мягкие 17 на
  подложенных колодах;
* формула отдачи костей против 300 000 симуляций, плюс сверка с классическим
  крэпсом (должен дать известный край 1.41%);
* общий банк: 100 раундов на четырёх столах, баланс сходится до рубля.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `bank.py` | общий кошелёк, джекпот, история, статистика по столам |
| `shell.py` | каркас: верхняя панель, вкладки столов, общая история |
| `widgets.py` | палитра, шрифты, кнопки, отрисовка карт |
| `games/base.py` | интерфейс стола и общее поле ставки |
| `games/poker.py` | видеопокер и джекпот |
| `games/roulette.py` | рулетка: сукно, колесо, разбор кликов |
| `games/blackjack.py` | блэкджек: шуз, правила, расчёт |
| `games/dice.py` | кости и точная формула отдачи |
| `cards.py` | карта, колода, перетасовка |
| `evaluator.py` | покерные комбинации, включая режим с джокерами |
| `paytable.py` | обе покерные таблицы выплат |
| `main.py` | запуск |
| `tests.py` | проверки честности и правил |
